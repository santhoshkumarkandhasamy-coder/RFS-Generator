# WIP - Final-format RFS builder (resume notes)

Goal (user request): rebuild the app so the generated workbook reproduces the Techfruits **Final** RFS file exactly
(structure, formulas, links, formatting, all 21 changes), with **no client data in code** - every figure comes from the user in the app.
Confirm with the user before generating the final output / pushing to main.

## User decisions (answered)
1. Groupings: fixed list of the Final's 87 masters + user custom masters; lines nil in every period are dropped automatically,
   except Schedule III mandatory rows.
2. FA register: support BOTH a standard template (app writes Schedule II WDV formulas) and mapping a client's own register.
3. Narrative text: default text from the Final wording with names/dates filled in, every paragraph editable; ratio variance
   reasons generated by formula.
4. Periods: stub + 3 FY when a stub TB is given, otherwise 3 FY.

- book.py          orchestrator `build(I, out_path)`; input-dict schema in the docstring; sheet order as the Final (29 sheets)

                   `{{ref}}` row tokens and `{NOTE:key}` note-number tokens resolved at the end, Annexure V groupings
- book_masters.py  masters -> note lines (Final order), custom masters
- book_inputs.py   MasterData, TB sheets (H natural-side sign, memo P&L rows when no P&L A/c ledger), ageing, shareholder register, Adj Entry RFS
- book_notes.py    Notes_Equity & Reserves, Notes_Liabilities (MSME (a)-(e), ageing 9(b)..), Notes_Assets (DTA, ageing 16(a)..), Notes_P&L
- book_fa.py       FA Register (standard / mapped -> normalised columns), FA Restatement Parts A/B/C, Notes_PPE (KMC blocks, CWIP/IAUD, ageing), PPE auto entries
- book_statements.py BS_1, PL_2, CFS_3, SAP_4 (policies a-q + useful lives), SOA_5
- book_annex.py    RPT, Gratuity and contingencies, Tax Computation, Accounting ratios, Analytical Ratios (4 blocks + formula reasons),
                   Borrowing Terms, Capitalisation, Additional Disclosures (i)-(xxiv)
- book_auto.py     auto entries: gratuity (actuarial DBO), MSME interest, current tax
- mapping.py / classify.py: STB masters aligned to the Final ("Bill discounting and trade finance loans (secured)",
  "Purchase bill finance and channel finance (unsecured)")
